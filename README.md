# G1-DRL-FINAL

本專案目標是依照 proposal 建立「深度強化學習量化交易系統」，讓代理人在非平穩市場中持續學習、動態決策與風險控管。

## 專案重點

- 混合感知：以 `CNN + LSTM` 擷取空間與時間特徵。
- 動態決策：整合 `PPO / A2C / DDPG`，以滾動視窗與夏普值進行策略輪替。
- 風險控制：加入 `Turbulence Index`，在極端市場觸發防禦機制。
- 市場擬真：導入 `StockMARL` 概念，模擬多種交易者互動生態。

## 基本流程

1. 資料整理與特徵工程（價格 + 技術指標 + 宏觀因子）。
2. 訓練多個 DRL Agent（含訓練/驗證切分）。
3. 以 rolling window 持續更新並挑選當期最佳策略。
4. 執行回測與風險評估（報酬、波動、回撤、夏普值）。
